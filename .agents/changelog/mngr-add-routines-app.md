The `manage-routines` skill replaces `manage-scheduled-tasks`, `enable-caretaker` and `disable-caretaker`: anything that runs on a schedule is a routine, made and changed with the `routines` command (`routines add <id> --every 1d --at 07:30 --skill <name>` or `-- <command>`), never a cron line; the Routines app is where the user sees, runs, pauses and retimes them. The `caretaker` skill carries the role its create template used to hold and retimes or switches itself off through the `routines` command; `build-app` says periodic work in an app is a routine with `--app <name>`, not a loop in the service; `check-app-errors` names the new skill.
