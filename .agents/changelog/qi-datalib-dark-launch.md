New skill: `datalib`, which searches and mirrors the user's own data (Slack, email, GitHub, Notion, chat history) with the datalib binaries. datalib is not announced to users yet, so the skill's description tells the agent to use it only when the user's own message says "datalib", and never to suggest or mention it otherwise. The skill starts the Datalib app (`supervisorctl start datalib`), which is stopped by default, and fetches datalib's Node runtime before the first sync.
