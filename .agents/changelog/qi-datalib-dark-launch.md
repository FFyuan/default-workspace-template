New skill: `datalib`, which searches and mirrors the user's own data (Slack, email, GitHub, Notion, chat history) with the datalib binaries. datalib is not announced to users yet, so the skill's description tells the agent to use it only when the user's own message says "datalib", and never to suggest or mention it otherwise. Nothing of datalib is installed at boot: on first use the skill runs its `scripts/install_datalib.sh`, which downloads the pinned release (v0.42.0, the static musl build, about 80 MB) into `~/.local/share/datalib/<version>/`, links every binary into `~/.local/bin`, and fetches datalib's Node runtime (about 115 MB). The skill then starts the Datalib app (`supervisorctl start datalib`), which is stopped by default.
