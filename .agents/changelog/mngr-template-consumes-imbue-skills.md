- The `minds-api` skill is now a thin companion to the published `imbue-studio` skill (from the `imbue-studio-skills` plugin every workspace carries): it no longer repeats how to reach the API, read the schema, or poll operations, and keeps only what applies from inside a workspace: the gateway's permission verbs (now matching the gateway's own list, which has no `-sharing` verb and does have `-backups-manage`), the create-from-here rules (branch from `GET /api/v1/app/version`, backups left unconfigured), the SSH and backup-export flows, and the pointer to `migrate-workspace`.

- Agents on harnesses that do not load Claude or Codex plugins (pi, opencode, antigravity) no longer get the full API walkthrough from `minds-api`; its summary of the gateway call form, the schema, and operation polling is what they have, and the published skill's longer guidance is not reachable from them.
