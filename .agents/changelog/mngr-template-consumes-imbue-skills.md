- The published `imbue-studio` skill (from Imbue's `imbue-ai/imbue-skills` marketplace, where the mngr repository exports it) is vendored into `.agents/skills/imbue-studio/` and recorded in `.agents/skills-lock.json`, so every harness that reads the workspace's skills (claude, codex, pi, opencode, antigravity) has it. It teaches how to reach the Imbue Studio API from wherever an agent runs, that `GET /api/schema` is the live contract, how operations are polled, and what never to do with the user's credentials. It is refreshed like the other vendored skills (`npx skills update`); edit it upstream, not here.

- The `minds-api` skill is now a thin companion to `imbue-studio`: it no longer repeats how to reach the API, read the schema, or poll operations, and keeps only what applies from inside a workspace: the gateway's permission verbs (now matching the gateway's own list, which has no `-sharing` verb and does have `-backups-manage`), the `type: "workspace"` permission request, the gateway's grant-free routes, the create-from-here rules (branch from `GET /api/v1/app/version`, backups left unconfigured), the SSH and backup-export flows, and the pointer to `migrate-workspace`.
