The visiting-agent primer's apps table says what each app is for and where it describes its API (the manifest's `description` and `api_schema_path`), and tells an agent to fetch that OpenAPI document before reading an app's code. The `build-app` skill's scaffolder registers the schema route, writes both manifest keys and generates the test that keeps the document honest in every new app; the skill explains what an app owes the document (a docstring per view, models for validated routes). The scaffolder writes a `--description` with characters outside the basic plane (or quotes) into the manifest as TOML accepts them, rather than as escapes the manifest refuses.
