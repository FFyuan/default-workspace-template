New: the routines library, everything in the workspace that runs on a schedule. One TOML definition per routine under `system/routines/`, a scheduler (interval or one-off, time of day, weekdays, day of the month, catch-up after downtime, retry after a failed run), one runner for command runs and skill runs (which wake the routine's own chat and wait for the agent's turn through the chat app), per-routine state, an append-only run ledger with a log per run, notifications to the Imbue Studio feed after repeated failures, on recovery and when an agent waits on the user, the `routines` command for agents, the cron env wrapper, and `routines migrate-cron`, which converts the cron entries a workspace wrote before.
