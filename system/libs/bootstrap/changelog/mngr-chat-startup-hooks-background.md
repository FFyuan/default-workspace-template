The bootstrap writes a second built-in cron entry at each boot, `/etc/cron.d/refresh-agent-tools`, which runs `system/scripts/refresh_agent_tools.sh` hourly through the env wrapper and `run_job.sh` (`--every 1h --retry-after 15m --wake-grace 10m`). It keeps the venv, the Claude plugins in every Claude config dir, and the shared Codex code-guardian copy up to date, in place of the work new chats used to do at startup.
