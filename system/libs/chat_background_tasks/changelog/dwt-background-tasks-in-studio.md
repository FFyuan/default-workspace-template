New stdlib-only library holding the background tasks each chat waits on: the marker files under `data/.apps/chat/background_tasks/<chat-id>/` and their liveness rules (`markers`), the chat-app-first listing with its fallback to the files (`listing`), and Claude's adapter, which records what its Stop hook reports, clears a gone Claude's markers at SessionStart, and on a resume names the tasks the restart ended (`claude`). A task's `source` is `run_in_background` or `harness`, and a harness task names its harness (`claude`). The chat app, the shell's avatar, `memory_candidates.py`, `create_worker.py` and `system/scripts/background_tasks.py` import it, instead of loading a script by path.
