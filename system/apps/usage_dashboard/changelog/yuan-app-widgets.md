Usage widget: the Usage app declares a `[widget]` at `/widget`, so the desktop shows subscription limits and this month's API spend in a corner. Expanded, it has one row per provider; collapsed, it shows two concentric hairline rings per subscription (the weekly limit outside, the 5-hour limit inside, in the limit colours, with the figures on hover), else the month's spend. It says when usage is still being indexed, dims while reconnecting, hides itself when there is no usage yet, and opens the Usage window when clicked.
