The desktop gets a show-around tour: a few seconds after the owner first sees a new workspace, a card pops out beside the agent's avatar and walks through the agent, the workspace, the apps, connectors, file sync, backups, sharing, devices, feedback, AI providers, and durable apps, ending at the launcher. A card about a control of the Imbue Studio chrome (the workspace switcher, a workspace tab, the help button) asks the chrome to ring it through the new `minds:highlight-chrome` embed-contract message; the words never depend on the ring. Exiting early leaves one badge pointing at the launcher, whose new "Show me around" row runs the tour again from the first card at any time.

Whether the tour has run is one flag the shell keeps in `data/.state/system_interface/tour.json`, read and written through `GET` and `POST /api/tour`. The tour's two pictures (a computer and a phone; the provider menu) are hosted on the onboarding-media bucket under content-addressed names, not bundled.

For now the tour runs once per workspace; limiting it to a user's first workspace waits for the cross-workspace data sync.
