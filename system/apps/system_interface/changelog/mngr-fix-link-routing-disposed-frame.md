- An app can now take custom-scheme links (`slack:`, `paseo:`, `vscode:`) by registering a message handler for `open:<scheme>` (`open:slack`). The shell announces `opensCustomSchemeLinks` to Imbue Studio, which then hands it such links from the workspace's pages, and a page's click on one comes to the shell too. A custom-scheme link no app takes goes back to Imbue Studio, which asks before opening it in the app of the user's system; an older Imbue Studio that does not say it opens them gets the link as a popup, which it asks about the same way.
