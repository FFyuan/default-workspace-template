- The browser can now be previewed: update-self's check of a customized browser and update-app's preview can boot a throwaway copy beside the live one. Before, the service always bound port 8081, so a second copy could never start. It now reads `BROWSER_PORT` (default 8081), and the manifest's new `[preview]` table gives a preview its own ports, a copy of the saved fleet, and its own profile directory. The profile directory matters most: on startup the browser relaunches every profile under its root and deletes any its saved fleet does not name, so a preview sharing the live root would have run on, or deleted, the user's logins.

- The tests' own fixture that cleared `MINDS_CHAT_ID` and `MNGR_AGENT_ID` is gone: the pytest-workspace-env plugin now clears the whole agent environment for every test run.
