The browser's API document (`GET /api/schema`) now publishes a request and a response schema for every JSON route: the fleet listing, a create, the `new` launch path, the `open:url` handler, the window-closed hint (the shell's `WindowClosedHint`), the ownership commands (attach, acquire, handoff, release) with the control state they carry, and the stop/start/close/close-tab answers, each a model in `browser/api_models.py` that the route table in `runner.py` names and every parse and answer is checked against. The viewer's telemetry post keeps its byte-capped read of the request stream, documented as a list of `ClientTelemetryRecord`. Pages, the clipboard routes (raw bytes) and the three WebSockets are declared schemaless with their reason. Every refusal and failure of every route is now `{"detail": "<reason>"}` (the `error` key is gone, and the init gate's 503 says the fleet is still restoring in its `detail` instead of a `status` field); the fleet CLI, the viewer page and the README read `detail`, and the CLI treats a 503 on an ownership command as "try again shortly". A `POST /browsers` now needs a JSON object body (`{}` for the one browser), as the CLI always sent.
