New: the Routines app, one window over everything that runs on a schedule. The list shows each routine's health, schedule and next run, and its last run; a routine's page has Run now, On/Off, Change schedule, Fix it (a chat briefed on the failure) and Remove, and its run history with each run's summary and a link to its chat; a run's page shows its log as is. A field at the top of the list describes a routine to add, which opens a chat for the agent to write it; the rows group under the display names of the apps they belong to. A routine's notification from the Imbue Studio feed lands on its page.

The schedule dialog offers weekdays for a monthly cadence too; a run's page re-reads every 5 seconds while its run is going; a re-read that fails keeps the page's data and says so in a toast.
