New: the Routines app, one window over everything that runs on a schedule. The list shows each routine's health, schedule and next run, and its last run; a routine's page has Run now, On/Off, Change schedule, Fix it (a chat briefed on the failure) and Remove, and its run history with each run's summary and a link to its chat; a run's page shows its log as is. A field at the top of the list describes a routine to add, which opens a chat for the agent to write it. A routine's notification from the Imbue Studio feed lands on its page.
