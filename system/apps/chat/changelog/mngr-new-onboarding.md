The welcome chat's agent starts as soon as the user signs in to a provider, rather than on their first message: the sign-in the chat's "Connect an AI provider" chooser produces launches a chat still awaiting its first send with no message, so the agent is up before the user has typed. The first message sent to it then carries the seeded onboarding conversation ahead of the user's words (as the launch used to), once; a slash command sent first goes as typed and leaves the conversation for the next message. The chat record carries `is_seed_pending` for this; a record written before it reads as delivered.
