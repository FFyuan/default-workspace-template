The `publish_cgroup_meminfo` program (local docker workspaces under runc) now publishes MemAvailable as the cgroup limit minus usage plus only the inactive file cache, the same signal the kubelet evicts on and the same change as the gen-2 VM's publisher in mngr. It used to add the active file cache and reclaimable slab too. Near the limit those are what the kernel thrashes rather than frees, so the figure could not fall far enough for earlyoom's SIGKILL threshold to fire before the cgroup OOM killer did.
