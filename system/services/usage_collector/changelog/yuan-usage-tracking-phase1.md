New service: `usage-collector` records every model call made in the workspace as one `model_call` event in SQLite under `data/.apps/usage/`, and serves cost and token totals (`GET /v1/totals`, grouped by any attribution field, model, billing mode and time bucket) and a live stream of new calls (`GET /v1/stream`) on 127.0.0.1:8795.

Events come from agents' mngr_usage event files (followed about once a second, with the place in each file kept across restarts), from apps through `POST /v1/events`, and from `claude -p` one-shots through `POST /v1/claude-sessions`, whose calls it reads from the session log with mngr_usage's reader and then deletes the log. It drains the spool emitters write while it is down. Events are idempotent by id; an unknown cost is stored as unknown, never $0, and a token-only event is priced from mngr_usage's price table. Visitors on a shared workspace are refused.
