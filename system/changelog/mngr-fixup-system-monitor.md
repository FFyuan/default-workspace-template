Added `docs/design/system-monitor-mocks/`: static HTML design mocks for the Memory & disk app, with the shipped page reproduced on sample data and ten variants that add CPU usage and try different layouts (overview tiles, tabs, Activity Monitor and Task Manager styles, AI token usage, a timeline, a per-chat view, a pinned widget, a health-first page, and a terminal look). `index.html` frames each one at the app's usual window size. Nothing in the app itself changes.
