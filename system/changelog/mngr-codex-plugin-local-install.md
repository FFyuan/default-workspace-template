A new Codex chat no longer waits for code-guardian to be cloned from GitHub before it starts. Each new Codex agent used to fetch the plugin's marketplace from GitHub during its create (about 1.5 s on a cloud workspace, and once 93 s when the fetch hung). The workspace now keeps one installed copy in `data/.state/codex-plugins/`, and a new agent copies it in tens of milliseconds. After that, a background run refreshes the shared copy from GitHub, so a code-guardian update reaches the next new Codex chat rather than the one being created. Only the first Codex agent on a workspace still installs from GitHub, and its install becomes the shared copy.
