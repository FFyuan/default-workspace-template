A new chat no longer waits for the plugin install/update or `uv sync --all-packages` before it can take its first message. Claude takes no prompt until all of its startup hooks have finished, and those two were the slow ones: the plugin install/update alone starts several `claude plugin` runs and checks the marketplaces on GitHub. Both now start from one hook, `system/scripts/claude_session_start_background.sh`, which runs them detached at a lower CPU priority, each stopped after ten minutes, and returns at once. Plugins are still checked at every chat start, but one check at a time per account and project path, so opening several chats at once starts one check; the warnings a background run prints are shown to the next session instead of the current one.
